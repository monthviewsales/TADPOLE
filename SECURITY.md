# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in **TADPOLE**, please report it responsibly.

**Do NOT open a public GitHub issue for security-sensitive findings.**

Instead, contact:

- 📧 Email: SummonTheWarlord@pm.me
  
Please include:
- A clear description of the issue
- Steps to reproduce (if applicable)
- The affected version or commit
- Any relevant logs or screenshots

## Scope

This project is currently **pre-production / experimental**.

Security reports related to:
- Private key handling
- RPC interactions
- Data integrity
- Supply-chain risks
- Unexpected fund movement (future versions)

are especially appreciated.

## Response Expectations

- We will acknowledge receipt when possible.
- Fix timelines depend on severity and project bandwidth.
- No bug bounties are offered at this time.

## Responsible Disclosure

We ask that you give us a reasonable opportunity to investigate and address reported issues before public disclosure.
